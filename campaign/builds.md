# Сборки (примеры направлений для эссенций)

Автор, 27.10.2026: это ТОЛЬКО ПРИМЕРЫ. Будут и другие; можно предлагать свои. Эссенции делаются с оглядкой на сборки (часть эссенций — сами по себе, не все идут к сборке).

**Танки:** через броню; через отхил.
**Поддержка:** через баффы; хиллер; через дебаффы.
**Копейщик:** на бросок; на дальность атаки; на подвижность.
**Фантомы.**
**Мечник:** скоростной; на разрушительную мощь.
**Снайпер:** на урон; со скрытностью.
**Скрытность:** убийца; связка «скрытность — разведка».
**Маг через эссенции:** на огневую мощь — через огонь, через молнию, через ветер; защитный маг — через землю, через лёд и воду.
**Призыватель. Некромант.**
**Рапира:** через урон по области; через редкие сильные атаки.
**…и так далее.**
