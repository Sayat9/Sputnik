Звуки игры. Положите сюда файлы (mp3/ogg), названия и отрезки — в SFX_MAN (index.html). Если файла нет, звук просто не играет.
- cave-1..5.mp3 — звуки пещеры (раз в 10–20 с в лабиринте, для всех игроков); нарезка из ролика, или целый файл + start/end в SFX_MAN
- battle-cave.mp3 — музыка боя в пещере (зациклена)
- fail.mp3 — выпала 1 (играет 0–1 с); crit.mp3 — выпала 20 (играет 5–7 с файла)
