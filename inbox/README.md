# Входящие картинки

Сюда автор кладёт картинки для игры вместо отправки в чат.

## Как загрузить
1. Открыть на GitHub папку `inbox` → **Add file → Upload files**.
2. Перетащить файлы (png, jpg, webp) и нажать **Commit changes**.
3. Написать Claude в чате: «картинки в inbox».

## Как назвать файл (по желанию)
Имя подсказывает, что это за картинка; если имя непонятное — Claude опознает по содержимому и промтам из `app/docs/missing_image_promts.md`.
- монстр: `monster-<id или название>.png` (полный рост 1024 × 1536);
- предмет: `item-<id или название>.png`;
- событие: `event-<название>.png`;
- здание / NPC / раса: `building-…`, `npc-…`, `race-…`.

## Что делает Claude
Забирает файлы, опознаёт, сжимает в `.webp` нужного размера, кладёт в `app/assets/…`, прописывает в `RASTER`, удаляет промт из `missing_image_promts.md` и убирает обработанный файл из `inbox` (в отчёте пишет, какой файл куда ушёл).
