# Спутник исследователя

Приложение-помощник для D&D-кампании «Выживание за варвара».

- `app/` — само приложение (`index.html`, картинки, заметки `CLAUDE.md`).
- `android/` — обёртка Android; `android/build.sh` собирает APK.
- `www/` — собранная версия для телефона: отсюда приложение скачивает обновления без переустановки.
- `campaign/` — правила кампании (`rules.md`) и заметки для работы с автором.
