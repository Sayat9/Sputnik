# Промпты для картинок предметов

Стиль — по `docs/art-style.md` (решение автора 17.10.2026): не слишком тёмно, не слишком реалистично (рисованное фэнтези-RPG), потёртость у снаряжения, читаемый силуэт, квадрат 1:1, без текста. Сохранять в `assets/items/<файл>.webp` (потом поправить `ART` в `index.html`; пока работают SVG-заглушки).

Оружие и снаряжение стоят на деревянной подставке, всё остальное — на небольшом каменном пьедестале с янтарным камнем в грани.
