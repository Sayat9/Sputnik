# Проверки тактического боя

Скрипты Node + Playwright (Chromium). Запуск из этой папки: `NODE_PATH=$(npm root -g) node <скрипт>`; путь к Chromium — `CHROME=...`,
папка скриншотов — `SHOTS=...` (по умолчанию `/tmp/battle-shots`), страница — `APP_URL=file:///.../index.html` (по умолчанию `app/index.html`).
Скрипты читают файлы боя прямо из `../../assets`, поэтому проверяют текущий код.

## Без интерфейса (быстро)

| Скрипт | Что проверяет |
| --- | --- |
| `bsim.js N` | N случайных боёв (случайные отряды и монстры 1 этажа); инварианты: ОЗ, мана, позиции, наложения, длина боя |
| `bbal.js N УР` | баланс: отряд из 3 героев против каждого монстра 1 этажа (1–3 шт.): победа, отступление, поражение, потери |
| `brules.js` | частота попаданий при преимуществе, помехе, укрытиях, обороне и т. д. против ожидаемой |
| `blog.js монстр,монстр` | печатает журнал одного боя (смотреть поведение монстров) |
| `essence_dc.js [id,id]` | каждая активка эссенции 1 и 2 этажа: расход маны и времени, Сл спасброска в журнале против формулы «8 + БМ + мод.» из текста (расхождения помечены) |
| `bsim_gear.js N` | бои со случайным снаряжением (всё оружие, доспехи, щиты, предметы), без исключений и мусора в журнале |
| `bact_gear.js N` | меню действий героя при случайном снаряжении: нет «undefined» и пустых действий |
| `bfix.js` | регрессия исправлений по аудиту эссенций (27 проверок): атаки по возможности, скрытые ловушки, вырваться, кровотечение, яд и вампиризм вурдалака и летучей мыши, рывок волка, Сл активок |
| `bdraft.js` | создание героя через настоящий `finishDraft`: у лучника колчан на 40 стрел, у мечника стрел нет |
| `bnew.js` | скорость в клетках (герои и монстры 1 этажа), подсыпка местности и заросли, автоконец хода (`turnSpent`), колчан на 40 стрел, исходы выстрела с принудительными кубиками (1, промах, впритык, попадание, крит) и доля поломок ≈ 15 %, бросок копья; подбор оружия — свободное действие, только стоя на его клетке (с соседней клетки нельзя), возврат стрел и оружия по итогам боя |
| `bess2.js [id,id]` | **эссенции 2 этажа (35 шт.)**, 422 проверки (в том числе регрессия по независимому аудиту, блоки `audit-*`): каждая пассивка и активка в управляемых условиях (принудительные кубики, слабый манекен — все характеристики 1, крепкий — 30): числа, Сл, мана, тип действия, перезарядки, статусы, призванные, зоны, тела |
| `bess2_sim.js N [id,id]` | автобои по N штук для каждой эссенции 2 этажа (случайные отряды, оружие, монстры 1 этажа): исключения, инварианты (ОЗ, мана, позиции, наложения), мусор в журнале, применяет ли ИИ автогероя способность |

## Общий прогон приложения

`app_sweep.js` — обход всех страниц, меню героя, библиотеки, сохранений (в приложении по умолчанию тактический бой включён); `app_fuzz.js N ШАГОВ` — случайный игрок по лабиринту с проверкой инвариантов, тактический бой выключен (бои идут в старом окне).

`app_fuzz_tactical.js N ШАГОВ` — то же, но тактический бой включён: каждая встреча автоматически доигрывается через интерфейс боя (авто-герои, быстрый режим), проверяются инварианты приложения после боёв.

Важно: кнопки боя помечены `data-ba`, а не `data-act` — `data-act` обрабатывает меню лабиринта в `index.html`.

- `bapp_special2.js` — особые места 2 этажа (гнездо, чернокрыл, часовня, ярусы, паутина, сокровища, пыль, неупокоенные); `bsim_special2.js` — автобои: паника последней вороны, подкрепление чернокрыла, составы ярусов.
- `bapp_town.js` — город: магазин (покупка и продажа, окно предмета по удержанию), монеты, таверна, часы врат и перенос усталости, библиотека, доска, гильдия, башня магов, церковь.
- `bapp_forge.js` — кузница: цены, стальные предметы (+1 к атаке, урону и КД, метка при экипировке), колчан и пайки в магазине.
- `bapp_ess_link.js` — название эссенции известно после впитывания, свойства скрыты; анализ в башне пишет в библиотеку, прочитанное в библиотеке открыто у эссенции.
- `bapp_treasures2.js` — кубики, колокольчик, фляга (откаты), библиотека артефактов и «??», определение в Башне магов, таблица находки сокровища к20, удача от призванных и на арене.
- `bapp_misc3.js` — подсказки по месту, режим мастера, заставка боя, список бросков на эссенцию (+ статистика 6 %).
- `bdice3d.js` — объёмные кубики: многогранники, числа, выпавшая грань к зрителю.
- `bact_misc2.js` — копьё на 2 клетки (помеха, укрытие), щит −2 к Скрытности, варвар «Великан» −2.
- `baudit_targets.js`, `baudit_sim.js` — аудит целей способностей монстров (по способностям и по случайным боям).
- `bapp_reset.js` — «Начать с нуля» в Сохранениях: подтверждение, слот «Партия до сброса», возврат.
- `bapp_again.js` — «Ещё раз»: перебросить бросок на эссенцию в окне наград.
- `bapp_treasures.js` — Огонь-путеводитель, Вечный очаг, Чаша здоровья (пруды, вода в бою, Отдых, город), Удача новичка, список убийств героя, библиотека без метки опыта.
- `bapp_guard.js` — сокровище «Ночной страж»: 3 заряда, +2 за первый спуск на новый этаж, караул в Отдыхе без ночных встреч, сброс в новом заходе.
- `bapp_ruins.js` — Волчья чаща: руины зданий 2 × 2 у выходного портала (границы, находка вдвое чаще, таблицы поиска с предметами, рисунки, окно поиска).
- `bapp_quests.js` — доска заданий: 2 за возвращение, принять/сдать из сумки для камней, окно продажи (галочки, ползунки), перенос старых камней, сгорание (камни остаются), последний шанс; `bapp_arena.js` — арена (ставки, бой отряда: награда ×3, без лута, бонус за эссенцию, усталость, запрет ночлега), цены эссенций, башня 1/3, церковь, гильдия.
- `bnew4.js` — окружение, Треск костей на одну цель, сводка массовых спасбросков.
- `bnew5.js` — штрафы Ловкости, вращающийся удар, короткий лук с ножом.
- `bbal4.js [N] [монстр] [k/n]` — баланс 7–8 класса: 4 героя 1 уровня против одиночек и стандартных групп (таблица побед, wipe, потерь ОЗ).
- `bnew6.js` — топь клыка и тьма крота с тёмным зрением.
- `brift.js` / `bapp_rift.js` — Кристальный разлом (монстры в бою; вариант этажа, алтари, Сердце). `bbal4c.js` — баланс разлома.
- `bweap.js` — оружие 2 (кровотечение, оглушение, парирование, выпад, слабое место, секира, перчатки, посох, топоры, прицел), расы и Академия на уровне данных. `bapp_academy.js` — экран Академии, покупка курсов. Известные устаревшие проверки скорости в `bnew.js` (5) и `bess2.js` (17): ожидания не обновлены после снижения движения.
- Онлайн: `bnet_link.js` (связь на loopback), `bnet_app.js` (ведущий и игрок на приложении: комната, зеркало, свои герои, ограничения, возврат сохранения), `bnet_battle.js` (удалённый ход героя, броски на телефон игрока, обрыв посреди хода), `bnet_battle_ui.js` (интерфейс боя у игрока), `bnet_peer.js` (настоящий PeerJS). Нужен http-сервер на :8765 с корнем `app/` (кодировка utf-8), страницы — `?net=loopback` (и `&mode=player` у игрока).

- `bapp_flute.js` — флейта: исходы по броску (без навыка, с навыком, успокоения), кнопка и эффект в Отдыхе, сундук крысолова.
- `bflute.js` — бой: действие «Флейта успокоения» (+2 клетки отряду, раз в день).

- `bapp_create.js` — создание героя: чтение бонусов, вторая перчатка/топор, бросок характеристик 4к6 ×8.

- `bnet_lobby.js` — лобби: два игрока и ведущий создают героев одновременно, все видят общую группу; выход и повторный вход; закрытие и новое открытие комнаты.

- `bswap.js` — смена оружия, два двуручных у варвара, лук с кинжалом.
- `bnet_version.js` — проверка версии при входе и исключение игрока.
- `bnet_spectate.js` — зрители онлайн-боя: расстановка, броски, сводки с переброском только владельца, скрытые КД/эссенции.
- Карта 2 этажа: пиксельные тайлы по местам и особые клетки (скриншоты — tools/battle-tests, bapp_floor2/bapp_rift).
- `bnet_crawl.js` — два клиента (ведущий и игрок, loopback): на каждом экране (главная, город, лабиринт, справочник, персонаж, библиотека) нажимает все видимые кнопки, кроме разрушающих («Закрыть комнату», «Выйти»…); следит за ошибками страницы, статусом связи игрока и совпадением отряда.
- `bnet_play.js` — настоящий ход игрока по сети: движение (тап по клетке + «Идти»), меню «Атака», выбор цели, бросок попадания и урона кубиком, «Конец хода»; проверяет, что позиция и убитый гоблин совпали у игрока и у ведущего. Ведущий-герой и монстры бросают автоматически.
- `bapp_floor3.js` — 3 этаж: расклад порталов (перестановка, бросок в начале 2-го дня), геометрия 31 × 31, 4 входа + портал дальше, обратные порталы в «свой» вариант, работа до конца 14-го дня и отключение с 15-го, случайный повторный спуск, срок 21 день, экран и карта.
- `bnet_sum.js` — сводка спасбросков по сети: игрок видит окно и перебрасывает только своего героя; ведущий — только героев без владельца.
- `bapp_void.js` — Безвременье 3 этажа: геометрия 4 × 4, случайные шаги, нет памяти, выход и центр только случайно.
- `bapp_f3zones.js` — зона ловушек (капкан, растяжка, валун, проверки внимательности/Ловкости) и преследователь охотничьих угодий (появление, шаги, видимость 3 клетки, граница, сброс и ускорение).
- `bess_scale.js` — все эссенции 7 класса: минимум 2 минуса и ≥ 5 плюсов. `bess2.js swamp-fang` — болотный клык (пассивка, активка, особенности монстра).
- `bapp_artboots.js` — сапоги скороходы, экстракт ветра, 3 уровень за 40 опыта, достижения за порталы.
