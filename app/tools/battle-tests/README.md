# Проверки тактического боя

Скрипты Node + Playwright (Chromium). Запуск из этой папки: `NODE_PATH=$(npm root -g) node <скрипт>`; путь к Chromium — `CHROME=...`,
папка скриншотов — `SHOTS=...` (по умолчанию `/tmp/battle-shots`), страница — `APP_URL=file:///.../index.html` (по умолчанию `app/index.html`).
Скрипты читают файлы боя прямо из `../../assets`, поэтому проверяют текущий код.

## Без интерфейса (быстро)

| Скрипт | Что проверяет |
| --- | --- |
| `bsim.js N` | N случайных боёв (случайные отряды и монстры 1 этажа); инварианты: ОЗ, мана, позиции, наложения, длина боя |
| `bbal.js N УР` | баланс: отряд из 3 героев против каждого монстра 1 этажа (1–3 шт.): победа, отступление, поражение, потери |
| `brules.js` | частота попаданий при преимуществе, помехе, укрытиях, обороне и т. д. против ожидаемой |
| `blog.js монстр,монстр` | печатает журнал одного боя (смотреть поведение монстров) |

## В браузере (настоящий интерфейс)

Общая обвязка: `bui_lib.js` (запуск, отряд, встреча), `bui_flow.js` (ход героя, лист броска, модальные окна), `bui_bot.js` (простой игрок).

| Скрипт | Сценарий |
| --- | --- |
| `bui2.js` | расстановка героев, первый ход |
| `bui4.js` | движение, атака, отмена на листе броска, бросок кнопкой |
| `bui5.js` | бой до конца ботом, экран награды, возврат в лабиринт |
| `bui6.js` | экран наград: два вращающихся d10 и выпадение эссенции |
| `bui8.js` | бросок кубика зажатием и броском, переброс |
| `bui9.js [id,id]` | все 20 навыков эссенций 1 этажа через интерфейс (выбор целей, листы, расход маны) |
| `bui15.js` | реакция, спасбросок от смерти, преимущество, урон с критом |
| `bui17.js` | сенсорный ввод (тапы, бросок кубика пальцем) |
| `bui19.js` | кнопка «Назад» телефона в бою |
| `bui20.js` | экран лабиринта после боя работает как раньше |
| `bui22.js` | ход монстров в засаде |
| `run_monkeys.sh СИД` | шесть случайных боёв параллельно (`bui_monkey.js`): зависания, ошибки, нарушения инвариантов |

## Общий прогон приложения

`app_sweep.js` — обход всех страниц, меню героя, библиотеки, сохранений (в приложении по умолчанию тактический бой включён); `app_fuzz.js N ШАГОВ` — случайный игрок по лабиринту с проверкой инвариантов, тактический бой выключен (бои идут в старом окне).

Важно: кнопки боя помечены `data-ba`, а не `data-act` — `data-act` обрабатывает меню лабиринта в `index.html`.
